# soyjutex.github.io

Sitio personal de soyjutex, publicado con GitHub Pages.

Para editar el contenido:

- `index.html` — estructura y textos de la pagina
- `style.css` — colores, tipografia y diseno
- `script.js` — logica simple (año del footer)

## Publicar cambios

```sh
git add .
git commit -m "descripcion del cambio"
git push
```

La web queda visible en `https://soyjutex.github.io` tras un par de minutos.
